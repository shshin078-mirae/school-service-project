2이미지를 웹페이지에 넣어보기

ImgBB란? 이미지를 인터넷에 올리고 웹페이지에서 사용할 수 있는 이미지 주소(URL)를 만들어주는 서비스입니다.
왜 사용할까? 이미지를 HTML 안에 직접 넣을 수도 있지만 코드가 길고 복잡해질 수 있어, 오늘은 이미지 주소만 연결하는 방법을 사용합니다.

이미지를 웹페이지에 넣는 5단계

1
이미지 검색
2
이미지 저장
3
ImgBB 업로드
4
직접 링크 복사
5
웹페이지에 적용

연습용 웹페이지 만들기

먼저 이미지가 들어갈 자리를 연습하기 위해 간단한 카드형 웹페이지를 만듭니다.

제미나이 열기 ImgBB 열기
사진과 제목이 들어가는 카드 2개가 있는 아주 간단한 연습용 웹페이지를 만들어줘. 각 카드에는 이미지가 들어갈 공간과 제목이 보이게 해줘. 디자인은 단순하게 해줘. 외부 라이브러리는 사용하지 말고, HTML, CSS, JavaScript를 모두 하나의 파일에 넣은 단일 HTML 파일로 만들어줘.

첫 번째 이미지 같이 해보기

1. 이미지 검색 — 필요한 이미지를 하나 찾습니다.

2. 이미지 다운로드 — 컴퓨터에 저장합니다.

3. ImgBB 업로드 — 저장한 이미지를 ImgBB에 올립니다.

4. 직접 링크 복사 — Direct Link를 복사합니다.

5. 웹페이지에 적용 — 제미나이에게 아래처럼 요청합니다.

1번 카드 이미지에 이 주소를 사용해줘: [ImgBB 직접 링크]

두 번째 이미지는 혼자 해보기

이번에는 내 서비스에 사용할 이미지를 하나 찾아 같은 방법으로 두 번째 카드에 넣어봅니다.

⚠️ 학생 얼굴, 이름표, 전화번호 등 개인정보가 보이는 이미지는 사용하지 않습니다. 인터넷 이미지는 오늘 수업 연습용으로 사용합니다.
ImgBB 이용이 원활하지 않을 때
패들렛에 이미지를 올린 뒤 해당 이미지를 클릭하고 이미지 주소를 복사해서 사용할 수 있습니다.

3내 서비스 웹페이지 만들기

localStorage = 지금 사용하는 브라우저가 기억하는 저장공간
F5를 눌러도 저장한 내용이 남을 수 있지만, 다른 친구 컴퓨터와 자동으로 공유되지는 않습니다.
여러 사람이 같은 데이터를 함께 보려면 공용 데이터베이스가 필요합니다.

※ 이 온라인 활동지도 여러분이 작성한 내용을 잃지 않도록 같은 브라우저의 localStorage에 자동 저장하고 있습니다.
